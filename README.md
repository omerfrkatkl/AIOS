# AIOS

A personal AI operating system: a permanent brain that lets you work with any AI — any model, any interface, any provider — without losing context, forgetting decisions, or repeating yourself.

## What it is

AIOS is a file-based "brain" (markdown + git) plus a set of deterministic enforcement tools:

- **Permanent memory** — state, decision history, and an approved/rejected/deferred ledger that survives session, tool, and model changes.
- **Decision discipline** — evidence-tagged records, tiered decisions, a scoring pipeline backed by research, and a gate that blocks re-proposing rejected ideas.
- **Resource intelligence** — a provider/channel inventory (subscriptions, APIs, free tiers, local models) with automatic routing and failover.
- **Personal knowledge** — deep personal context lives in an Obsidian vault, queried surgically instead of re-asked.

The long-term goal, the requirements, and the build plan are all versioned in this repository:

- [`vision.md`](vision.md) — the north-star (owner's wishes, in the owner's words)
- [`REQUIREMENTS.md`](REQUIREMENTS.md) — falsifiable requirements derived from the vision
- [`PLAN.md`](PLAN.md) — the 17-phase rebuild map with progress tracking
